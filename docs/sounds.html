SIGNAL PACK

Original synthesized terminal sounds inspired by REPLACED. No game audio is included. Files are CC0 and can be replaced with your own captures using the same names.

Receive

receive.wav

Generic incoming message. Short descending terminal chirp.

Reply

reply.wav

Reply in a server. Two-step up/down signal.

Mention

mention.wav

Mention alert. Three ascending square-wave pips.

Send

send.wav

Transmit click. Key press with a low terminal thump.

Hover

hover.wav

Menu cursor tick. Very short, low-volume phosphor blip.

Select

select.wav

Menu confirmation. Descending terminal pair.

Back

back.wav

Menu back. Lower descending response.

Mute / Unmute

mute.wav / unmute.wav

Down and up toggle pair for microphone state.

Deafen / Undeafen

deafen.wav / undeafen.wav

Heavier toggle pair with a short noise tail.

Join / Leave

join.wav / leave.wav

Voice channel arrival and departure sweeps.

Disconnect / Reconnect

disconnect.wav / reconnect.wav

Signal loss and link restoration.

Ring

ring.wav

Call ringing loop fragment.

Success

success.wav

Confirmation chime for completed actions.

Error

error.wav

Low clipped buzz for failed actions.

Boot

boot.wav

CRT power-on sweep for theme or plugin startup.

Type

type.wav

Key tick while writing a message.

Open

open.wav

Menu or modal powering on.

Close

close.wav

Menu or modal collapsing.

Navigate

navigate.wav

Two-step blip when switching channel, server or tab.

Toggle

toggle.wav

Switches and checkboxes.

Camera on

camera-on.wav

Rising sweep when video starts.

Camera off

camera-off.wav

Falling sweep when video stops.

Clip

clip.wav

Clip saved.

Stage

stage.wav

Three-note waiting cue for stages.

PLAYING THEM IN DISCORD: Themes are CSS-only and cannot play audio, so the ReCord userplugin does it: it replaces Discord's sounds and adds interface sounds. The installer sets it up on Vesktop by default. The event mapping is in sounds/README.md and sounds/manifest.json.
